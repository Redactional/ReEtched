# Security policy

Please report security problems privately, not in a public issue: use **[Report a vulnerability](https://github.com/Redactional/ReEtched/security/advisories/new)** on the repository's Security tab.

Include what's affected, how to reproduce it, and the version. You'll get a reply within a few days, and fixes are released as soon as they're ready.

Only the latest release receives security fixes.
